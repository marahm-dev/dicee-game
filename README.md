# Dicee Game 🎲

A simple two-player dice game.
Each refresh rolls a die for both players and the page shows who wins.

**Live demo:** https://YOUR-USERNAME.github.io/dicee-game/

## Built with

- HTML
- CSS
- JavaScript (DOM manipulation)

## How it works

Each player gets a random number from 1 to 6.
The higher number wins, and equal numbers are a draw.

## What I learned

- Selecting and changing elements with `querySelector`
- Generating random numbers with `Math.random()`
- Using functions and if/else logic
